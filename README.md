# SwapSim 地図版

本家 SwapSim の生成エンジンを移した、独立してビルド・公開する地図版です。本家のリポジトリに接続する必要はありません。土地用途や施設ごとに人物を抽選し、東京23区を対象とします。

## 実行と更新

Node.js 20以上で `npm run build` を実行すると、`dist/` に静的サイトを生成します。`npm test` で主な整合性を確認できます。各モジュールとデータは `map-preview/` に、共通する人物生成コードの複製はルートにあります。更新の際はこのリポジトリのファイルを編集します。

GitHub Pages の公開元を GitHub Actions に設定すると、main への更新で自動ビルド・公開します。生成物の HTML、人物生成プログラム、地図データは別ファイルに分けて配信し、旧メッシュは表示時のみ読み込みます。公開用の地図データは経緯度を小数6桁（約10cm）に丸め、地図範囲外の水域を除いて軽量化します。背景地図は人物生成データの読み込み完了を待たずに先に表示します。

背景地図、施設データの補完、現在の天気は外部サービスへの通信を利用します。取得できない場合、収録済みの地理情報や天気の推定値を使います。イベント日程は収録済みの公式情報と推定を併用し、自動更新はされません。
